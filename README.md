# Progetto HTML-CSS: Boolando - E-commerce di abbigliamento

## Descrizione

Questo progetto è un sito web di e-commerce dedicato alla vendita di abbigliamento, con un design pulito e moderno.

### Struttura Principale

- **Header**: contiene il logo, le categorie principali di prodotti (Donna, Uomo, Bambini) e le icone per l'account utente, i preferiti e il carrello.
- **Main**: presenta una griglia di schede prodotto (card), ciascuna con immagine, nome del brand, nome del prodotto, prezzo nuovo e prezzo vecchio (scontato), e badge informativi come sconti percentuali o indicazioni di sostenibilità. Le immagini cambiano al passaggio del mouse per un effetto dinamico.
- **Footer**: include informazioni legali e link alle pagine di privacy, diritto di accesso, oltre ai collegamenti ai principali social network con icone FontAwesome.

### Aspetti Tecnici e Stilistici

- Utilizzo di font personalizzati (Whitney e Whitney-Bold).
- Layout responsive centrato con uso di flexbox per allineamenti.
- Uso di overlay sulle card per evidenziare preferiti, sconti e sostenibilità.
- Palette colori calda e contrastante (arancione brillante per l'header, rosso per sconti, verde per sostenibilità, nero/grigio scuro per il footer).
- Interazioni hover per immagini prodotto e icone.
